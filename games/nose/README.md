# 你画我猜 · 鼻子版

用**鼻尖当画笔**，在空中写字让朋友猜。

## 操作

| 动作 | 效果 |
| --- | --- |
| 移动鼻子 | 画笔移动 |
| 按住鼠标在画板上拖 | 擦掉经过的线条 |
| 「落笔 / 抬笔」按钮 | 切换笔画 |
| `N` | 完成这一题，下一题 |
| `C` | 清屏重画本题 |
| `Z` | 撤销上一笔 |
| `R` | 重新开始一轮 |

## 玩法

每题弹出 5 个候选词挑一个，用鼻尖在空中"写"出来，**45 秒一题，共 5 题**。
结束后进画廊，可下载 PNG。

## 技术

- **MediaPipe FaceMesh** —— 取鼻尖关键点（index 1），比全身 Pose 的鼻子精度高得多，且只需露脸
- 鼻尖归一化坐标镜像后，相对校准基准的偏移 × 灵敏度 → 映射到画板
- **指数滑动平均**（α=0.45）平滑抖动，增量连线绘制
- 笔画存成 `strokes` 数组（每条含 `mode: draw|erase`），所以擦除可撤销、可重绘、可导出
