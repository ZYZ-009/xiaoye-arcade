# NEON DRIFT · 体感版

霓虹街机赛车。抬下巴踩油门，歪头过弯。

## 操作

| 动作 | 效果 |
| --- | --- |
| 抬下巴 | 油门 |
| 低头 | 刹车 |
| 歪头向左 / 向右 | 车辆转向 |
| 平视 | 定速巡航 |

漂移 / 氮气仍由键盘控制。`C` 键随时重新校准中立姿势。
键盘备用：`W/S` 加减速。

## 玩法

- 3 圈制，4 台车竞速（你 + 3 名 AI）
- 冲出护栏不会卡住，而是触发一次受控复位，自动滑回赛道中央
- 复位后有短暂无敌，防止刚回中线又被甩出去

## 技术

- 原生 Canvas 伪 3D
- **MediaPipe FaceLandmarker**（478 点）
- 两个姿态量：
  - `pitch = (鼻尖y - 双眼中点y) / (下巴y - 双眼中点y)` → 抬下巴变小
  - `roll = atan2(两外眼角y差, 两外眼角x差)` → 歪头
- 相对校准基线超过死区才触发，带迟滞防抖
- 人脸丢失 > 0.8s 自动进入巡航保护，避免"幽灵操作"
