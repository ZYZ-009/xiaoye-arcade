# 像素CSGO · 体感版

Minecraft 风格的方块战场射击，五波敌人。

## 操作

| 动作 | 效果 |
| --- | --- |
| 身体左右倾 | 左右走位 |
| 上身前倾 / 后仰 | 前进 / 后退 |
| 原地跑动 | 疾跑 |
| 右手比「手枪」手势 | 持续开火 |
| 左手举过头顶 | 抛手榴弹 |
| 右手贴耳边 | 呼叫炮火支援 |

`C` 键重新校准站姿。键盘全程可以接管。

## 玩法

- 五波生存，每波敌人数递增，同屏最多 10 个
- 靠近宝箱会自动展开防护罩并解开一道数学题（体感版全自动）
- 圣水可以满血复活并获得 3 秒无敌；局末自动存进仓库，下一局可携带

## 技术

- **Three.js** —— 3D 方块战场
- **MediaPipe Pose**（身体倾斜、跑动）+ **Hands**（手枪 / 举手 / 贴耳手势）
- 体感版无限弹药、无需换弹
