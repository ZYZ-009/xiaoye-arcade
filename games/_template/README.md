# 游戏模板

复制这个文件夹做一个新游戏：

```bash
cp -r games/_template games/你的游戏名
```

## 要改三处

1. **`index.html`** —— 换成你的游戏
2. **本文件** —— 改成你游戏的说明（参考下面格式）
3. **`src/page.html` 里的清单** —— 加一条记录

## 本文件建议格式

```markdown
# 游戏名

一句话说明这是什么。

## 操作

| 动作 | 效果 |
| --- | --- |
| 往左挪 | 角色往左 |

## 玩法

规则说明。

## 技术

用了什么（MediaPipe Pose / Three.js / 纯 Canvas…）。

## 作者

你的 GitHub ID
```

## 硬性要求

- 入口必须叫 `index.html`
- 纯前端，不能有后端
- 能在 iframe 里跑
- 用了摄像头的话，退出时记得释放
