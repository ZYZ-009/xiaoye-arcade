# 脖子碰碰车

用头开的 3D 碰碰车竞速。转头转向，抬下巴加速。

## 操作

| 动作 | 效果 |
| --- | --- |
| 头往左转 | 车子左转 |
| 头往右转 | 车子右转 |
| 抬下巴 | 加速 |
| 低头 | 刹车 / 后退 |
| 平视 | 保持 |

没有摄像头也能玩：`W/A/S/D` 或方向键。

## 玩法

- 环形赛道，共 3 圈，跑完按累计进度排名
- 每辆车 3 层护盾，撞墙前 3 次安然无恙
- 护盾耗尽后第 4 次撞墙 → 回到起点重跑，护盾恢复
- 车与车之间可以互相碰撞弹开

## 技术

- **Three.js** —— 3D 场景
- **MediaPipe FaceMesh** —— 468 点人脸网格推出头部姿态
- 姿态算法（轻量，不需要解 PnP）：
  - `pitch = (鼻尖y - 双眼中点y) / 眼距` → 抬头变小、低头变大
  - `yaw = (鼻尖x - 双眼中点x) / 眼距` → 头右转变大
- 开局自动校准 2 秒，记录平视基准；之后都按"相对基准的偏移"来控制
- 带死区与平滑，避免抖动
