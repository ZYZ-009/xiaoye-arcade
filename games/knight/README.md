### 障碍配比：下蹲 : 跳跃 = 1 : 1

生成每一组障碍前，先从「配额袋」里取类型 —— 袋子里始终是一张"下蹲"、一张"跳跃"（顺序随机），取空再补，
因此**每 2 组里必有 1 组下蹲、1 组跳跃**，不会像纯随机那样出现连续偏科。两个池子内的模式权重也做过对齐，
让"下蹲障碍的个数"同样接近一半：

| 指标（前 120 秒实测） | 下蹲 | 跳跃 |
| --- | --- | --- |
| 生成批次（组数） | 约 50% | 约 50% |
| 障碍个数 | 约 50%（49–56%） | 约 50% |
| 公平性测试中 AI 操作次数 | 下蹲 112 次 | 跳跃 118 次 |

### 下蹲障碍一览

| 障碍 | 破解方式 | 说明 |
| --- | --- | --- |
| 横梁 `bar` | 下蹲（跳跃也能勉强越过） | 开局第一组就是它，3 连排布 |
| 长横梁 `beam` | **长按 S** | 150px 宽的整段横梁，短按 S 来不及 |
| 蝙蝠 `bat` | 下蹲（会上下浮动） | 3 只一队 |
| 低天花板 `ceil` | 与长横梁组队 = 下蹲隧道 | 位于跳跃最高点之上，**跳（含二段跳）必撞**，只能蹲过去 |
| 箭矢 `arrowLow` | 跳跃或下蹲均可 | 原既有类型 |

## 🎮 游戏玩法

- 扮演一位绿甲骑士，在无尽的中世纪荒野中奔逃
- 躲避尖刺、木箱、木桶、哥布林、史莱姆、巨兽、箭矢、蝙蝠、横梁等障碍
- **血量系统**：基础 5 点，撞障碍 -1；🧪 药水 +1（不超上限），❤️ 空中红心 +1~+2（**可超上限**），护盾免费挡 1 次
- **金币（数值制）**：触到 1 枚金币 **+10 数值**（宝石 +50），多多收集增强成就感；**保命机制**：被打到 **1 血**时自动扣 **2 数值**回满血
- 收集金币、宝石，拾取**护盾 / 磁铁 / 双倍积分 / 药水**道具
- **慢节奏**：世界滚动速度起步仅 **165px/s**、每 2 秒 +2、上限 **380px/s**（原版 240→520），障碍每 **1.5–2.2 秒**一组；
  配合"不按 A/D 即静止"，观察、走位、起跳都有充裕时间
- 场景氛围随时间从**黎明 → 白昼 → 黄昏 → 夜晚**循环变化
- 最高分自动保存在浏览器 `localStorage` 中

### 操作方式（桌面端 WASD 自由移动）

| 操作 | 桌面端 | 移动端 |
| --- | --- | --- |
| 向右移动 | `D` / `→`（只有按住才动） | — |
| 向左移动 | `A` / `←`（只有按住才动） | — |
| 静止 | 不按 / 同时按 `A`+`D` | — |
| 跳跃（第一级） | `W` / `↑` 或 `空格` | 点击屏幕 |
| 二段跳（第二级） | `空格`（空中再按） | 空中再次点击 |
| 下蹲（穿过低矮障碍） | `S` / `↓`（可长按保持） | 向下滑动 |
| 暂停 | `P` / `Esc` | 左上角按钮 |
| 重新开始 | `R` | 结算界面按钮 |
| 静音 | `M` | 主菜单勾选项 |

> **移动规则（硬性）**：角色**不会**自动跑动，位移只由 `A` / `D` 产生，松手立刻停住，受击也不会被击退。
> **障碍规则**：尖刺/木箱/木桶/哥布林/史莱姆/巨兽 → **跳跃**（巨兽需二段跳时机）；
> 横梁/长横梁/蝙蝠 → **下蹲**通过；**天花板隧道 → 只能下蹲**；箭矢 → 跳跃或下蹲均可。
> **血量**：基础 **5 点**，撞障碍 **-1 血**，受击后 1.5 秒无敌帧（防连环扣血）；
> 药水 **+1 血**（不超上限），**空中红心 +1~+2 血且可超过 5 血**（上限 10，HUD 显示 `+N`），
> 护盾免费挡 1 次，血量归 0 即失败。

## 🎮 体感版（摄像头动作操控）

**入口 `体感版.html`**（与键盘版 `index.html` 并存，互不影响）。基于 MediaPipe（Pose 全身 33 点 + Hands 双手 21 点）捕捉身体动作驱动骑士：

| 你的动作 | 游戏操作 | 判定信号 |
| --- | --- | --- |
| （自动） | **人物自动向右跑**，身体左右不控制移动 | `motion.js` 的 `enableLateral=false`（需开启左右控制时改 `true`） |
| 原地跳起 | 跳跃（第一级） | 髋部快速上移（瞬态，蹲姿期间抑制防误跳；1 帧即触发，延迟更低） |
| 跳起来双手拍一下 | 二段跳（更高） | 双腕距离 < 0.15（由游戏侧过滤"仅空中有效"） |
| 蹲下并保持 | 下蹲（穿障碍 / 隧道） | 髋 y 低于校准基线 + 膝弯 <110°（稳态） |
| 鼠标按钮 | 暂停 / 继续 / 开始 / 重开 | 菜单与 HUD 按钮（体感版已关闭键盘 P/Esc 与握拳暂停） |
| 键盘 W / 空格 / S | 跳跃 / 二段跳 / 下蹲（兜底） | 体感与键盘可混用 |

### 校准与手感

- 点「开启体感」后自动进入 **2 秒站立校准**（记住你的髋部基线，不同身高/站位都适配）；可随时点「重新校准」。
- **灵敏度 3 档**（迟钝 / 标准 / 灵敏），运行中可调，实质是缩放左右死区。
- 摄像头**画中画**（右下角，可关闭）显示你的骨架叠加；HUD 下排 5 个**动作指示灯**实时显示识别结果。
- 人体短暂丢失（出画面/被遮挡）会自动回"静止"，不会卡住操作。

### 实现说明

- `js/motion.js`：摄像头 + 双模型启动（裁剪自 gesture_tracker）+ **纯函数 `parseMotion()`** 做动作判定 + 平滑/锁存/校准；
  核心判定不依赖浏览器，可被 `test/motion-check.js` 直接单测。
- `js/input.js`：新增 `inject(act)` 接口，把动作状态写入既有输入通道 —— **游戏引擎（game.js）零改动**，键盘/触摸全部保留。
- 判定关键点：Pose 11/12 肩、23/24 髋、25/26 膝、27/28 踝、15/16 腕；Hands 21 点。
- 注意：摄像头画面为镜像，控制以画面为参照（所见即所得）；多人入镜时以置信度最高者为准。

## 🧪 自动化测试

```bash
node test/smoke.js          # 冒烟测试：启动→游玩→生成→碰撞→死亡→结算→重开 全流程
node test/fairness.js       # 公平性测试：AI 自动玩家运行 250 秒，验证所有障碍可躲避
node test/wasd-check.js     # A/D 直接速度控制：默认静止 / 松开即停 / 世界滚动
node test/controls-check.js # FATFIGHT 回归：严格 A/D 移动 + 空格二段跳 + 开局下蹲障碍
node test/motion-check.js   # 体感映射单测：左右/跳跃/下蹲/二段跳/暂停/丢失保护
```

`controls-check.js` 覆盖的关键断言：

1. 不按 / 松开 / 同时按 A+D → 位移恒为 0；按住 D 右移、A 左移；**受击后位移仍为 0**
2. 空中再按 `W` 不产生二段跳；空格在地面起跳、空中再按一次 `jumps = 2` 且顶点更高
3. 开局 1.5s 第一组障碍为下蹲型；前 120s 内**生成批次**与**障碍个数**的下蹲占比都在 50% 附近（45–58%）
4. 长横梁/隧道：站姿与跳跃均扣血，**按住 S 无伤通过**
5. 空中红心：**站立够不到**、跳起来才能撞到；3 血→4/5、4 血→5/6、5 血→6/7；达上限 10 不再增加；前 120s 生成 ≥20 颗
