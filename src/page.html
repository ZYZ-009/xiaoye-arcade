    想加一个游戏？

    不用注册本站账号，用 GitHub 就行。审核通过后，所有人的网址上都能玩到。

    去 GitHub 开始制作 › 看别人的游戏源码
    1. 复制模板 games/_template/
      改名成 games/你的游戏名/，往里填内容
    2. 把刚复制的模板贴进 src/page.html 的清单里
    3. 跑一次 python build/build.py，本地确认能玩
    4. 提 Pull Request，我审核合并 → 网址自动更新
